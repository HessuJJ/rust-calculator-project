This is a simple calculator made with rust.

Ai was used to do the submission.

I used AI to find out how to check input without .expect that the program does not panic and continues until correct input is provided or user exit's the program.
AI suggested to use ""match" in main first but i wanted to use it in read_input so i asked how to do that.
I checked the ""match" pattern matching from the rust documentation and then used i in the read_input function.
From this I learned to use "match" and while writing this i realized that i could also done this with "if/else".
But if I understood "match" correctly, it can more flexible than "if/else" in some situations.
